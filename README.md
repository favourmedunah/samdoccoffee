Samdoc Coffee & More — Website
"Life Happens, Coffee Helps"
A single-page, multi-view website for Samdoc Coffee & More, a café in Emaudo, Ekpoma, Nigeria. Built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step.
🌐 Live Demo
View Live Site 
✨ Features
Animated loading screen and scroll fade-in effects
Responsive navbar with mobile hamburger menu
SPA-style view switching (Home, Menu, Story, Order, Contact) without page reloads
Full menu organized by category (beverages, protein, pastries, breakfast, appetizers, pasta, noodles, small chops)
Shopping cart with quantity controls and live total
Order checkout flow with delivery/pickup toggle and payment options
Orders and contact messages sent directly via WhatsApp
Customer reviews and Instagram feed section
Floating WhatsApp chat button
🛠️ Built With
HTML5
CSS3 (custom properties / design tokens)
Vanilla JavaScript
Google Fonts — Playfair Display & Inter
Unsplash — imagery
